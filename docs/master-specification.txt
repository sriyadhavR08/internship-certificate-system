# 1. PROJECT PURPOSE

Our organization provides internships lasting between 1 and 3 months.

Currently, after a student completes an internship, we manually print certificate content on an existing certificate/bond sheet.

We want to digitize this process.

The new system should allow:

Student Registration
→ Login
→ Internship Details
→ Internship Completion
→ Admin Approval
→ Certificate Preview
→ Certificate Generation
→ QR Code Generation
→ Digital PDF Certificate
→ Student Download
→ Public Certificate Verification

The system must remain small, simple, secure and professional.
